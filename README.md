# Centre Les Profs

## Installation
```bash
npm install
npm run dev
```

Ouvrir ensuite: http://localhost:3000

## Fonctionnalités
- Site public responsive
- 3ème année collège
- Tronc Commun
- 1ère année Bac
- 2ème année Bac
- Dashboard Admin
- Gestion des élèves
- Gestion des professeurs
- Gestion des matières
- Emploi du temps
- QR Code individuel
- Présence: présent / absent / retard
- Paiements
- Annonces
- Statistiques

### Note
Cette version fonctionne immédiatement avec localStorage. Pour une vraie base de données multi-utilisateurs, la prochaine étape est Supabase.
